# ny

Neural network verifier. Prove your AI correct. Inspired by alpha-beta-CROWN.

ny is made by [ALab](https://alab.systems). Its source code is not published:
this repository carries ny's binary releases, their release notes, and its
license.

## Install

Install it with aterm's package manager, which verifies every signed binary:

```sh
aterm pkg install ny
```

Every release is listed under [Releases](https://github.com/alabsystems/ny/releases),
and its notes are in `release-notes/`.
