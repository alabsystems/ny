# External conformance suites

The default `ny-onnx` test suite is hermetic and has no ignored tests. Tests
that require a generated model, a separately downloaded competition corpus,
or accelerator hardware are explicit conformance jobs instead of silently
skipped unit tests.

Run them through the launcher:

```sh
cargo run -p ny-onnx --bin ny_onnx_conformance -- whisper --lib
cargo run -p ny-onnx --bin ny_onnx_conformance -- avoice --lib
cargo run -p ny-onnx --bin ny_onnx_conformance -- vnncomp
cargo run -p ny-onnx --bin ny_onnx_conformance -- wgpu --lib
```

The suites are:

- `avoice`: real `speaker_encoder.onnx`, `talker_attention_layer0.onnx`,
  `kokoro_vocoder.onnx`, and `kokoro_duration_predictor.onnx` exports. Set
  `NY_TEST_MODELS_DIR` or place them under `tests/models/`.
- `whisper`: `whisper_tiny_encoder.onnx`, generated by
  `scripts/export_whisper_encoder.py`.
- `vnncomp`: benchmark corpora installed by
  `benchmarks/download_benchmarks.sh`, plus any result artifacts named by an
  individual diagnostic.
- `wgpu`: a compatible live WGPU device. The `avoice-gpu` and `vnncomp-gpu`
  variants combine hardware with the corresponding external corpus.
- `all`: every lane above.

Arguments after the suite name pass directly to `cargo test`, so `--release`,
test-target selection, filters, and libtest arguments work normally. Enabling
a lane registers its tests; a missing required file or device is a failure,
never a successful early return. The launcher defaults Cargo and runtime
parallelism to one unless the caller has already set an override.
